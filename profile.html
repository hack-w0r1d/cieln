About

Ciel'N（しえるん。）です。HTML / CSS / JavaScript を軸にしたフロントエンド開発を中心に、配信アプリ「Mirrativ」向けのツールや情報サイトを制作しています。

個人開発をしている理由

昔から、自分で作ったものを誰かに使ってもらいたいという思いがありました。ただ、現実的に自分で作れるものがなかなか見つからず、形にすることができずにいました。

そんな中、自分が多くの時間を使っている配信アプリやゲーム、そして現代に欠かせない存在になったAIを組み合わせれば、「あったらいいな」を自分の手で形にできるかもしれないと気づきました。得意な分野でスキルを磨きながら、開発経験を積めるチャンスでもあります。

実際に制作したサイトやツールを公開し、色々な人に使ってもらう中で、一定の需要に応えられるものを作れているという実感が自信につながり、開発そのものを楽しみながら続けられています。
