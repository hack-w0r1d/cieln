制作ノート：LiveTelop Makerをモジュール分割した話

LiveTelop Makerのリファクタリングで考えたことと、速度スライダーの工夫を記録しています。

きっかけ

LiveTelop Makerは、最初は1つのscript.jsに機能を集めて作っていました。機能を足すたびにファイルが長くなり、どこを直すとどこに影響するのかが読み取りにくくなったため、モジュール分割に踏み切りました。

分割の構成

state / premium / storage / telop / main の5つのESモジュールに分けています。

  • state：アプリ全体で共有する状態
  • premium：プレミアム機能まわりの処理
  • storage：設定などの保存・読み込み
  • telop：テロップの描画（Canvas）
  • main：初期化と、各モジュールのつなぎ込み

循環参照をどう避けたか

モジュールを分けると、AがBを読み込み、BがAを読み込むという循環参照が起きやすくなります。そこで、呼び出したい関数をモジュールの外から渡すコールバックパターンと、共有のstateオブジェクトを経由して値を受け渡す方法を組み合わせ、モジュール同士が直接依存し合わないようにしました。

速度スライダーの区分線形補間

テロップの速度を変えるスライダーには、区分線形補間を使っています。スライダーの区間ごとに基準となる値を決め、その間を直線でつなぐ方法で、なめらかに速度が変化します。
